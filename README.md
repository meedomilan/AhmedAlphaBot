Crypto Futures Pump & Dump Bot 🚀
بوت احترافي مطور لمراقبة عقود الفيوتشر (Futures) على منصة باينانس واكتشاف التحركات السعرية وحجم التداول غير الطبيعي مبكراً.
التحديثات الجديدة (الإصدار المعقول)
مراقبة الفيوتشر: البوت يراقب الآن جميع أزواج USDT في سوق العقود الآجلة.
إعدادات حساسة: تم تقليل العتبات لاكتشاف الحركة في بدايتها:
تنبيه عند ارتفاع/انخفاض السعر بنسبة 0.8% في دقيقة واحدة.
تنبيه عند وصول حجم التداول إلى 2.5 ضعف المتوسط.
دعم الاتجاهين: يرسل البوت تنبيهات للصعود (Long) وللهبوط (Short).
المميزات
مراقبة لحظية لجميع عقود الفيوتشر النشطة.
روابط مباشرة لفتح صفقات الفيوتشر فور وصول التنبيه.
نظام تسجيل (Logging) لمتابعة أداء البوت على الاستضافة.
المتطلبات
Python 3.9+
Telegram Bot Token & Chat ID.

تأكد من وجود المتغيرات البيئية TELEGRAM_TOKEN و TELEGRAM_CHAT_ID في إعدادات Railway.
